# ⚜️ Dust & Debt — The Frontier Chronicle

> *The wilderness offers opportunity. The ledger demands payment.*

**🪶 This game was made entirely using GPT 5.6 sol.**

A Western browser game told here as an adventurer’s old manuscript. Take a bounty, saddle a horse, follow a treasure map and return to a tavern of your own. Between journeys, try the race hall, casino or market—then face the debt at the end of the month.

**[⚔️ Play in Chrome](https://cnsdqd-dyb.github.io/dust-and-debt/) · [📦 Download](https://github.com/cnsdqd-dyb/dust-and-debt/releases/tag/v51.5.2) · [📚 All 38 originals](VERSIONS.md)**

Recommended build: **V51.5.2** · Game interface: **Chinese** · Introduction: **English / 简体中文** · Best on desktop Chrome.

## 🕯️ Before setting out

Use desktop Chrome and stay online for the first visit: the 3D tavern loads Three.js and external model resources. Audio may begin after your first click. Follow the controls shown inside the game.

Progress uses browser `localStorage`. Different browsers, sites and local files can have separate saves. Export your save in the game before switching versions or clearing site data.
