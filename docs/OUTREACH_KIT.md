AI 快速做出一款真正可玩的游戏，离我们还有多远？我们用 GPT 5.6 sol 做了 51 个版本

### 正文

如果把需求、代码、界面和一次次修复都交给 AI，一款浏览器游戏可以走到什么程度？

我们把这个问题做成了一款能直接玩的西部游戏：《尘土与债务》。玩家从酒馆接悬赏，骑马进入 96×96 的荒野，追捕目标、搜集情报、淘金寻宝；回城后还可以交易、赛马、玩赌场、经营坐骑和布置 3D 酒馆。月底的债务把这些玩法串成同一场生存压力。

这个游戏完全使用 GPT 5.6 sol 制作。仓库保留了 38 份 HTML 原件，从早期版本到 V51.5.2 都能查看。现在也加入了 English Beta，让海外玩家可以体验核心路线。

这次实验给我们的答案并不是简单的“AI 已经能做游戏了”。AI 的确能非常快地扩展玩法、写出大量代码并持续迭代；但当系统越来越大，稳定性、统一设计、少见事件、本地化和完整测试会迅速成为新的瓶颈。英文 Beta 可以覆盖核心流程，但随机长文本仍可能出现中文；原版也留有已记录的脚本问题。AI 缩短了从想法到可玩原型的距离，但从“能玩”到“值得长期玩”，仍然需要人的取舍、测试和品味。

## Reddit: r/playmygame / suitable indie-dev showcase communities

### Title

How far are we from making a real game quickly with AI? We built 51 iterations of a Western browser game

### Post

We have been testing a concrete question: how far can AI take a game from an idea to something people can actually play?

The result is **Dust & Debt**, a Western browser game made entirely using GPT 5.6 sol. You take bounties from a 3D saloon, ride across a 96×96 frontier, gather clues, hunt targets, follow treasure maps, trade, race horses, gamble, collect mounts, and try to survive the debt at the end of the month.

We preserved 38 original HTML builds so the iteration history is visible instead of presenting only the polished endpoint. We have also added an English Beta that translates the core routes. Rare event text may still appear in Chinese.

The experiment has been encouraging and humbling. AI made it surprisingly fast to add systems and produce a broad playable prototype. The hard part moved to consistency, testing, long-tail bugs, localization, and deciding which ideas deserve to stay.

### Short description

### Description

**The wilderness offers opportunity. The ledger demands payment.**

Dust & Debt is a systems-heavy Western browser game. Begin in a 3D saloon, choose a bounty, ride into a living frontier, gather clues, prospect for treasure, trade on the frontier exchange, bet on horse races, collect mounts, and return with enough money to face your creditor.

This project asks a practical question: **how far are we from making a real game quickly with AI?** The game was made entirely using GPT 5.6 sol and developed through more than fifty named iterations. AI made breadth and iteration surprisingly fast. Coherence, testing, localization, and the long tail of bugs remain the difficult part.

The English Beta covers core routes; rare event text may remain Chinese. Desktop Chrome is recommended.
