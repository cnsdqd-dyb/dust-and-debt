# 实机截图 / Gameplay capture notes

本画廊的 16 张画面均在 Chrome 中打开仓库中的 V51.5.2 原始 HTML，通过实际游戏界面截取。浏览器视口为 1440 × 900；部分菜单直接截取弹窗区域以提高可读性。没有生成或伪造游戏画面，没有修改游戏原件。

All 16 images are actual Chrome captures of the archived V51.5.2 HTML. The viewport was 1440 × 900; some menu images capture the modal directly for legibility. No gameplay image was generated or fabricated, and the original game files were not edited.

截图使用独立演示存档。为展示收费模式与地图生态，部分场景通过游戏内置测试面板设置资金或开启全图视野；它们展示界面和玩法，不代表正常流程赚取的进度。淘金截图为远征开局，藏宝图背包显示尚未结算的战利品规则。赛马结果是实际下注后的获胜画面。马厩画面展示当前持有坐骑；牲口市场展示可选坐骑，未使用空白繁育界面冒充已繁育成果。

An isolated demo save was used. Some paid expedition scenes use the game's built-in test panel to set funds or enable full-map visibility. These illustrate the features rather than earned progression. Gold Rush captures show an expedition's opening and the backpack's unbanked-loot rules. The race result is a real winning wager. The stable shows an owned mount; the market shows available animals. An empty breeding screen was deliberately excluded.
